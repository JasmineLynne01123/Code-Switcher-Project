# Code Switcher Project

A sleek, modern front-end landing page built to demonstrate interactive code switching for multiple API SDKs (TypeScript, Python, Rust, Go, cURL, Elixir, and Java).

## 🚀 Features
- **Interactive Code Tabs:** Instantly switch code snippets across multiple programming languages.
- **Responsive Layout:** Optimized for desktop and mobile viewports.
- **Modern UI/UX:** Clean dark theme with tailored developer documentation elements.

## 🛠️ Built With
- **HTML5**
- **CSS3** (Custom properties & Flexbox/Grid)
- **JavaScript (ES6+)**
